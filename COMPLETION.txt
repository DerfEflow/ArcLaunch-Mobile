ARCHITECTURE HIGHLIGHTS
  Request flow: Components -> apiClient.post/get/etc -> AsyncStorage queue if offline
  State management: Redux with redux-persist for automatic rehydration
  Sync status: App.tsx registers callbacks with apiClient for Redux dispatch
  Auth flow: Token stored in expo-secure-store, cleared on 401 response
  Offline detection: NetInfo listener updates sync state on connectivity change
  Message queueing: POST/PUT/PATCH/DELETE queued; GET requests not queued

HOW TO TEST OFFLINE FLOW
  1. Start app: npm run start:ios or npm run start:android
  2. Make changes offline: Disable network in simulator/device
  3. Confirm stage or send guide message - should queue locally
  4. Re-enable network - app should sync queued requests
  5. Verify changes appear in backend

HOW TO TRIGGER PUSH NOTIFICATIONS
  1. Configure push notification endpoint in backend
  2. Send test notification via Expo CLI:
     expo send:notifications --where "app.id=<project-id>"
  3. App should receive and display notification
  4. Tapping notification navigates to venture/guide via deep link
