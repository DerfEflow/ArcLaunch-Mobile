## Built With

This app is built with the following open-source technologies and frameworks:

### Core Framework

- **[React Native](https://reactnative.dev/)** - JavaScript framework for building native apps
- **[Expo](https://expo.dev/)** - Managed React Native framework with EAS Build and EAS Update

- **[Redux Toolkit](https://redux-toolkit.js.org/)** - State management with Redux
- **[redux-persist](https://github.com/rt2zz/redux-persist)** - Persist and rehydrate Redux state

### Navigation

- **[@react-navigation/native](https://reactnavigation.org/)** - Navigation library for React Native
- **[@react-navigation/stack](https://reactnavigation.org/docs/stack-navigator/)** - Stack navigator

## Contributing

When adding new dependencies:

1. Check license compatibility (prefer MIT, Apache 2.0, BSD)
2. Verify size impact (check bundle size)
3. Consider maintenance (prefer well-maintained packages)
4. Update this CREDITS.md file
5. Update DECISIONS.md if it's a significant architectural choice

## Reporting Issues

If you discover issues with any third-party libraries or dependencies:

1. Check the package's GitHub repository
2. Search existing issues
3. File a bug report if needed
4. Consider if there are alternative solutions
5. Document the issue in STATUS.md or DECISIONS.md
